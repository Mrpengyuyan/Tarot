# Phase 71 — 牌的悬停光与香炉火星

用户试玩后指出两处效果有问题，本期修复。实现在 `Editor/Phase71AnimationFixBootstrapper.cs`（菜单 `Tools/Tarot Unity/Run Phase 71 Animation Fix Bootstrap`，可以重复运行，连续运行两次文件哈希不变）。

## 牌的高亮

**问题：** 预制体 `PF_TarotCard` 里的 `Highlight` 是 Phase 2 灰盒阶段留下的一块不透明琥珀色立方体，比牌还大，直接盖在牌上。Phase 68 加了桌面光池以后，它被照得过曝，再经过辉光晕开，整张牌变成一块发光的黄板。

另外还有一个逻辑问题：发牌后 `DeckController` 会点亮每张还没翻的牌，表示「点我翻开」；但鼠标一移开，`CardClickHandler.OnPointerExit` 又把它关掉了。

**修复：**
- `Highlight` 改成一张平放的 Quad，材质用 `MP_WarmGlow`（与 Phase 61 牌位发光相同）。它放在牌底面之下、投影之上（本地 y = -0.045），尺寸 1.5 × 1.95，所以只有牌的四边会透出暖光。碰撞体已移除，不会挡住鼠标。
- `CardView` 把两种状态分开：
  - `SetHighlighted` 表示「等待翻开」，由发牌和翻牌控制；
  - `SetHovered` 表示「鼠标悬停」，悬停时光晕放大到 `hoverHaloScale` = 1.45 倍。
  - 只有背面朝上的牌才会发光。移开鼠标不会熄灭「等待翻开」的光，翻开之后光晕消失。
- 「等待翻开」的光刻意做得很淡：此时牌位本身已经在发光、呼吸，两者叠加会刺眼。悬停时的放大才是主要反馈。

实测：牌两侧一圈的平均亮度（满值 255），不亮时为 29.0，等待翻开为 32.2，鼠标悬停为 35.6。

## 香炉

**问题：** Phase 45 的「烟」是暖色发光贴图的粒子，每秒 5 个，几乎直线上升，看起来像一串往上爬的珠子。调参时试过两种办法，都不行：
- 加密：变成一根发光的金柱，一直冲到屏幕顶端；
- 调淡变稀：碗边剩两块亮斑。

用这张发光贴图做不出烟。

**修复：**
- 新增 `MP_Censer/Embers`：从炭火上迸出的火星。
  - 大小 0.02–0.045，每颗大小不同；
  - 颜色从橙黄渐变到暗红；
  - 用噪声让它们打旋，同时让大小闪烁；
  - 越往上升越快，1.6–3.2 秒内缩小熄灭；
  - 每秒 8 颗，偶尔一次迸出 2–6 颗；
  - 渲染为沿运动方向拉长的短条（Stretch），看起来像火星的轨迹。
- `Smoke` 停止发射，并关闭渲染。对象保留，因为 `Phase45MenuDepthTests` 会检查它是否存在。

## 测试与截图

- `Tests/EditMode/Phase71AnimationFixTests`：检查火星的参数、烟已停用、光晕的材质、网格、位置和朝向。
- `Tests/PlayMode/Phase71CardHoverTests`：发一张牌，依次验证：等待翻开时有光；悬停时光晕放大；移开后光仍在；翻开后熄灭；悬停已翻开的牌不再发光。
- `Editor/Phase71CaptureBuilder`：由环境变量 `PHASE71_CAPTURE_DIR` 指定输出目录，生成三张牌的截图（不亮 / 等待翻开 / 悬停），以及主菜单在粒子模拟几秒后的两张截图。火星的动态效果只能在 Unity 里看。
