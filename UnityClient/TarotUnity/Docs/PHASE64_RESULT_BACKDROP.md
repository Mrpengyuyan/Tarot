# Phase 64 — Result Backdrop + Quit Link

Two loose ends from the earlier front-end audit.

## Result screen parlor backdrop

The Result scene rendered its reading on a pure-black clear, while the menu and
reading room are warm candlelit parlors — so a spread looked like it floated in a
void, the single clearest inconsistency across the three screens.

`TarotBackdrop.png` (generated by `gen_uikit.make_backdrop`) is an aubergine
gradient with a warm candle glow rising from the lower centre, a faint sigil echoing
the menu's astrology circle, and a soft vignette — kept deliberately dark so the
gold/ivory reading text stays legible over it. The Phase 64 bootstrapper lays it as
`MP_ResultBackdrop`, the first (backmost) child of the Result canvas, full-screen and
non-raycasting, so it sits behind every reading element (hero card, spread band,
reading panel) without intercepting clicks. This ties the three screens together for
one-, three- and ten-card readings alike.

## Menu quit link

Phase 44 made the 离席 exit a "quiet link" (transparent plaque), but its label ink
had faded to a near-invisible grey. It is lifted to a restrained ivory that reads as
present without competing with the 入席问牌 invitation.
